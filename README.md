# J.A.R.V.I.S. - Sistema Operacional Avançado (v4.5)

Interface web futurista inspirada no J.A.R.V.I.S. do Universo Cinematográfico Marvel (MCU), integrada com um tema estilo Kali Linux, núcleo holográfico dinâmico, síntese e reconhecimento de voz, IA de alta velocidade via Groq API e autenticação via Firebase.

---

## 🚀 Funcionalidades Principais

* **Núcleo Holográfico Dinâmico:** Orbe central interativo que pulsa e reage visualmente de acordo com a frequência da voz ou respostas da IA.
* **Escuta Contínua e Voz:** Reconhecimento de fala integrado e síntese de voz customizada em português do Brasil (`pt-BR`) com tom robótico/profissional.
* **IA de Ultra-Velocidade:** Conectado à Groq API utilizando o modelo de alta performance para respostas instantâneas.
* **Gerador de Imagens Integrado:** Comandos diretos como *"Gere uma imagem de..."* criam artes visuais holográficas em tempo real.
* **Gerenciamento de Sessões e Histórico:** Histórico completo de conversas armazenado localmente (`localStorage`), permitindo alternar entre sessões ou reiniciar o sistema.
* **Layout Responsivo Otimizado:** Barra de input e ferramentas fixadas permanentemente para visualização perfeita em computadores e celulares.
