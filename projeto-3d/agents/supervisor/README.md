# JARV SUPERVISOR

## Objetivo
Garantir que nenhuma alteração vá direto para a branch 'main'.

## Diretrizes de Branches
- Correções de API: jarv-fix-api
- Correções de Login: jarv-fix-login
- Correções de Chat: jarv-fix-chat
- Correções de Interface: jarv-fix-ui

## Fluxo
Agent -> Branch de Feature -> Testes -> Review -> Pull Request -> Merge -> GitHub Pages
